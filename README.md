## ✨ What's inside?

Terminal Arcade is a collection of lightweight games designed to run directly in your terminal.

| # | Game | What you do |
|---|---|---|
| 1 | 🔢 **Guess the Number** | Find the secret number in as few guesses as possible |
| 2 | 🪦 **Hangman** | Guess the hidden word before the drawing is complete |
| 3 | ✊ **Rock Paper Scissors** | Battle the computer in a best-of-five match |
| 4 | ❌ **Tic Tac Toe** | Play the classic against a randomly-playing computer |
| 5 | 🪙 **Coin Flip** | Call heads or tails and test your luck |
| 6 | 🎲 **Dice Roll** | Roll the dice and see what you get |
| 7 | 🔮 **Magic 8-Ball** | Ask a question and receive a mysterious answer |

### 🏆 Also included

- **High scores** — save and view your best results
- **Terminal-first** — no GUI required
- **No runtime dependencies** — just Python
- **Beginner-friendly issues** — built for first-time contributors
